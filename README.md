# Branova Concepts Website

GitHub-ready frontend for **Branova Concepts Uganda Ltd** — Source • Brand • Supply.

## Run locally
Open `index.html`, or open this folder in VS Code and use Live Server.

## Structure
- `index.html` — homepage
- `assets/css/style.css` — styling
- `assets/js/main.js` — website interactions
- `assets/images/branova-logo.png` — official logo
- `assets/images/products/` — product photos

The package includes 15 starter product visuals in `assets/images/products/`. Replace them later with Branova's actual project photos while keeping the filenames to avoid changing code.
